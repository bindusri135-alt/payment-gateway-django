\# Payment Gateway Integration



A Django-based payment processing system developed as part of the Python Full Stack Internship.



\## Features



\- User Login and Authentication

\- Multiple Payment Methods

\- Payment Transaction Management

\- Payment Verification

\- Transaction History

\- Refund Handling

\- Webhook Endpoint

\- Payment Dashboard

\- Invoice Generation

\- Django Admin Panel



\## Technologies Used



\- Python

\- Django

\- SQLite (development)

\- HTML

\- CSS

\- Git \& GitHub
